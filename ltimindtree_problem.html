💡 Motivation

Why This Problem
Matters

Machine learning is widely used in healthcare to predict disease risks from clinical data. Quantum Machine Learning (QML) is an emerging field exploring whether quantum computing techniques can enhance machine learning tasks.

However, real-world structured datasets are often low-dimensional and noisy, raising an important question:

When does QML actually make sense for real-world data?

This challenge aims to evaluate the practical usefulness and limitations of QML using a real healthcare dataset.

Problem Statement

Participants must investigate whether QML provides meaningful advantages over classical ML for structured healthcare datasets.

Using the Pima Indians Diabetes dataset, teams must build baseline models, implement at least one QML model using a hybrid quantum–classical approach, and evaluate the impact of quantum constraints. The focus is not only model accuracy but also a critical evaluation of QML applicability.
Pima Indians Diabetes Dataset:

The dataset contains 768 patient records with 8 clinical attributes such as glucose level, blood pressure, BMI, insulin level, age, etc.
Task: Binary classification to predict diabetes risk.

🔑 Expected Tasks
  • Data Preparation
    Preprocess and analyze the dataset.
  • Classical Baseline
    Implement classical ML baseline models (e.g. Logistic Regression, Random Forest, SVM).
  • Quantum Model Implementation
    Implement at least one Quantum Machine Learning model using frameworks such as Qiskit or PennyLane.
  • Benchmarking and Analysis
    Compare classical and quantum model performance and provide analysis on whether QML is suitable for this problem.
